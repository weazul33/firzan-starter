---
name: explain
description: Explain a word, a change or a permission prompt in plain English, then check understanding.
disable-model-invocation: true
---

1. If they named something, explain that. If not, explain the last change or the last permission request.
2. Use plain English and one everyday comparison. Keep it under five sentences.
3. If it's a new word, add it to your list for "Words I've learned" in NOTES.md. It goes in with the next NOTES.md change. If they ask for it to go in now, add it now.
4. Ask them to say it back in their own words, in one sentence. If they've got it, say so. If not, try once more a different way.
