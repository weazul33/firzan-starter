---
name: check
description: Test the latest change like a careless user, then hand the learner three things to try.
disable-model-invocation: true
---

1. Open the page (docs/index.html) in the browser pane and test the latest change. Try it like a careless user: clicking things twice, every link, a narrow window like a phone. The browser pane shows one file and can't follow links, such as an email address or another page. For those, offer to open docs/index.html in their normal web browser (one permission box) and test the links there.
2. If there's no browser pane (for example in a phone session), read the changed files carefully instead, say plainly that you couldn't click it yourself, and tell them to check it on the live link right after /ship.
3. Tell them in plain words what you tried and what happened. If anything broke, say so plainly and don't fix it yet.
4. Give them three specific things to click or look at themselves, and what they should see. Ask them to try and tell you what happened.
5. When they report back, count habit 5. If it all works, suggest /save (at coaching level full). If something broke, offer to fix that one thing.
