description: Start a later session: where we are, the habit to focus on, one small next step.
disable-model-invocation: true
---

1. Read the brief (CLAUDE.md in the project's top folder), NOTES.md, HABITS.md and the newest file in reviews/.
2. In three lines: what works now, the habit the last review said to focus on (skip this line at coaching level light. Also skip it if "Session number" in CLAUDE.md is 3 or more and that habit is planning or checking: let them make the first move), and one small next step that fits in 15 minutes. If "Today" says something went in circles, say so in one line instead of the habit line, and ask them to describe the problem fresh in a few plain sentences. Don't retry the fixes it says failed.
3. Ask what they'd like to do today. Then let them make the first move.
