name: stuck
description: Work out what's wrong before changing anything.
disable-model-invocation: true
---

Don't change any files during this command.

1. If they haven't already told you, ask these one at a time: "What did you do?" "What did you expect to happen?" "What happened instead?"
2. Look at the project and the browser pane. Explain in plain words what you think is causing it, and how sure you are.
3. Offer two options, for example: try one specific fix, or /goback to the last saved version.
4. If this is the third attempt at the same problem, recommend /goback and say why in one sentence: more fixes on top of a broken step usually make it worse.
