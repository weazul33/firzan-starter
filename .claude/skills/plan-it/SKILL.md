disable-model-invocation: true

Don't create or change any files during this command, except NOTES.md in step 4.

1. Read "Done looks like" in CLAUDE.md.
2. Propose a plan of no more than five numbered steps. For each step, say in one line what the learner will be able to see or click when it's done.
3. Ask: "Is there any step you'd cut or move to later?" At coaching level full, add one line on why: smaller plans are easier to check and easier to undo.
4. When they're happy, add the agreed plan under "Plan" in NOTES.md (ask permission first like any file change) and count habit 2.
5. Say: "When you're ready, tell me 'Do step 1.'"
